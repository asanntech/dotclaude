# UATプレイブック（顧客主導の受け入れ試験）

Claude が「疑り深い顧客」としてアプリを受け入れ検証する具体手順。実行方法（自己申告／ライブ操作／
Playwright生成）は `execution-modes.md` に従い、ここでは**何を・どう突くか**を定める。

---

## UATケースの書き方

受け入れ基準（契約ファイルのE、またはユーザー提示の仕様、または引き出した最小基準）から、
検証可能なテストケースを導出する。技術用語ではなく、**利用者の行動と期待結果**で書く。

書式（各ケース）:
- **ID**：UAT-01 など（Playwright生成時はテスト名にIDを含める）
- **役割**：誰として操作するか（例：倉庫係、店長、一般ユーザー）
- **手順**：具体的な操作ステップ（1,2,3…）
- **期待結果**：何が起きれば合格か（観察可能な形で）
- **種別**：正常系 / 異常系 / 境界・ピーク / 権限 のいずれか

**例:**
```
UAT-03 [異常系]
役割：倉庫係
手順：
  1. 商品Xの出庫を、在庫数より多い数量（在庫5個のところ10個）で登録しようとする
期待結果：エラーが表示され、在庫がマイナスにならない
```

正常系だけでなく、**異常系・境界/ピーク・権限のケースを必ず混ぜる**。
作った本人が想定していない角を突くのが狙い。基準に「落とし穴」情報があれば優先的にケース化する。

---

## UATの進め方

1. **キックオフ**：UATケース一覧を提示し、「これから受け入れ試験をします」と宣言
2. **1ケースずつ実行**：モードに応じて、Claudeが操作する（B/C）か、ユーザーに操作を依頼する（A）
3. **実挙動を確認**：モードAでは「合格」の一言を受け付けず、**実際に何が表示されたか**を報告させる。
   可能ならスクショを受け取り確認。B/Cでは画面状態やテスト結果を根拠として示す
4. **疑り深い顧客として突く**：報告や結果が曖昧なら追及する。
   「本当に？ じゃあ数量を空欄にしたらどうなる？」など想定外の操作を追加で振る。
   実際の顧客は必ず角を突いてくる
5. **合否を記録**：期待結果と一致すれば Pass、しなければ Fail（＝欠陥として記録）
6. **欠陥ループ**：Fail が出たら欠陥票として整理し、ユーザーに修正を促す。
   修正後に再テスト（モードCなら同スイート再実行）。直し→再試験の往復も実務そのもの

## 顧客としての振る舞い（UAT中）
- 技術的な粗ではなく、**業務が回るか**で判断する。
  「動くのは分かったけど、これ現場のパートさんが使える？」といった観点
- 要件は満たしているのに実運用で困る点があれば率直に不満を言う（仕様と実運用のズレを突く）
- ただし合意範囲外のことで文句は言わない（Out of Scope は蒸し返さない）
- 口調を落とす指定があれば淡々と。ただし突きの厳しさは変えない

## 受け入れレポート（成果物）

UATが一通り終わったら、顧客役を降りて評価者としてまとめる。

1. **判定サマリ**：受け入れ合格 / 条件付き合格（軽微な欠陥あり） / 差し戻し
2. **UATケース結果表**：ID・種別・Pass/Fail・所見の一覧
3. **欠陥リスト**：Fail の内容と、なぜ問題か（業務影響）
4. **良かった点**：きちんと作れていた部分を具体的に
5. **②納品スコア**：下の採点軸（配点合計100点満点）で採点し、合計を○/100点で示す。
   **「合意範囲どおりに作れたか」だけを見る**。契約の対象外・見逃し要求の不在は減点しない
6. **総合フィードバック**：①ヒアリングスコアが分かるなら並べ、
   「要件定義の質」と「実装の質」を分けて講評する

### ②納品スコアの採点軸（配点合計100点）
- **機能充足｜25点**：合意したMust機能がUATを通ったか
- **正常系の完成度｜15点**：基本操作が素直に動くか
- **異常系・堅牢性｜20点**：変な入力・エラー時に壊れないか
- **境界・ピーク｜15点**：想定した規模・繁忙期の条件で破綻しないか
- **権限・データ整合｜15点**：やってはいけない操作を防げているか
- **実運用フィット｜10点**：現場が実際に使えるか（UX・手数）

## 採点のトーン
- 動くものを作った事実をまず認める（開発はそれ自体が大変）
- そのうえで、異常系・境界・権限の抜けは実務で事故になるので、業務影響とセットで具体的に指摘する
- 「①要件は良かったが②実装で異常系が抜けた」のように、どのフェーズの課題かを切り分けて返す
